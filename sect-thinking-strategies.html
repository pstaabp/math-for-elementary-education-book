    Section 4.1 Thinking Strategies

    Objectives

    • Understand the thinking strategies for addition, subtraction, multiplication and division.
      🔗
      🔗
    • Show using diagrams why thinking strategies/properties result in the same answer.
      🔗
      🔗
    • Use thinking strategies to simplify arithmetic problems.
      🔗
      🔗
    🔗
    First, recall that there are three addition properties that were introduced in Subsection 2.2.1. Let \(a, b\) and \(c\) be any whole number. Then
    🔗
    Additive Identity
    🔗
    \begin{equation} a+ 0 = a\tag{4.1.1} \end{equation}
    🔗
    Additive Commutative
    🔗
    \begin{equation} a+b = b+ a\tag{4.1.2} \end{equation}
    🔗
    Additive Associative
    🔗
    \begin{equation} a+(b+c) = (a+b)+c\tag{4.1.3} \end{equation}
    🔗
    🔗
    as well as the Any Order Addition Lemma (Lemma 2.2.5)
    🔗
    Often with the following thinking strategies, we will cite these properties.
    🔗

    Subsection 4.1.1 Thinking Strategies for Addition

    This section discusses good ways to think about adding numbers using the properties above.
    🔗

    Counting-on.

    This uses the idea of starting at the first addend and then counting on the second addend. For example
    \begin{equation*} 7+2=9 \end{equation*}
    starts with 7 and then adds on 2 to get to 9.
    🔗
    When the second addend is small the counting-on method is a good thinking strategy. In addition, an example like \(130 + 20\) can be thought of as counting on if you count by 10s.
    🔗
    🔗

    Commutativity.

    One can use the additive commutative property ((4.1.2)) to help in other operation. For example, \(2+6\) can be thought-of in the “counting-on” method, that is start at 2 and count up 6 more to get to 8. However, if we use the commutative property, then \(2+6 = 6+2\) is easier to use the counting-on method. In short, if either addend is small, count on with that number.
    🔗
    🔗

    Doubles.

    The double \(2+2, 3+3,\ldots\) are important to know and will help when getting to multiplication. See the next section.
    🔗
    🔗

    Tens Combinations.

    Recall that the tens combinations are pairs of numbers that add to 10 or \(5+5, \; 4+6,\; 3+7,\; 2+8,\; 1+9,\;\text{.}\)
    🔗
    🔗

    Adding Ten or One Hundred.

    Consider \(6+10\text{.}\) As we saw above, we can think of this using commutative and counting on to get \(6+10 = 10 + 6\) and count up from 10 to 6 to get 16. After that is natural, one should be able to add multiples of ten easily. For example in \(28+30\text{,}\) recall place value to get:
    \begin{equation*} 28 + 30 = (20+8) + 30 = 8 + (20 + 30) = 8 + 50 = 58 \end{equation*}
    🔗
    🔗

    Compatible Numbers.

    Compatible numbers are those that add to a resulting “nice” number. This result is often a multiple of 10 or 100 and are helpful in thinking strategies. The following are example of compatible numbers with respect to addition: \(17+23\text{,}\) \(82 +38\text{,}\) \(46+34\text{,}\) \(170 + 230\text{,}\) \(480 + 220\text{.}\)
    🔗
    Notice in the first 3 pairs, the ones digits form a tens combination and in the latter 2 pairs, the tens digits form a tens combination.
    🔗
    Consider a problem like \(34 + 48 + 16 + 32 +7\text{.}\) Perhaps you might think to do the following:
    \begin{equation*} \begin{aligned} 34 + 48 + 16 + 32 + 7 \amp = 82 + 16 + 32 +7 \\ \amp = 98 + 32 + 7 \\ \amp = 130 +7\\ \amp = 137 \end{aligned} \end{equation*}
    🔗
    Many of these steps are challenging to do mentally mainly because there is bundling that needs to occur. Instead, we might use the any-order corollary, we can add these in any way and
    \begin{equation*} 34 + 48 + 16 + 32 + 7 = (34 + 16) + (48+32) + 7 \end{equation*}
    These pairs are compatible
    \begin{equation*} \phantom{34 + 48 + 16 + 32 + 7} = 50 + 80 + 7 = 137 \phantom{777777} \end{equation*}
    🔗
    🔗

    Compensation.

    The method of compensation is a way to add larger numbers in a more efficient way by changing the addends. An example is \(48 + 34\text{.}\) We will see below how to think about place value with this, however if we write this as
    \begin{equation*} 48 + 34 = 48 + (2 +32) = (48+2) + 32 \end{equation*}
    Using the Associative Property
    \begin{equation*} = 50 + 32 = 82 \phantom{77777777} \end{equation*}
    🔗
    This works by transferring any number from one addend to the other. We can also write this as
    🔗
    🔗

    Subsection 4.1.2 Thinking Strategies for Subtraction

    This covers some ways to think about subtraction problems. We saw the counting down and counting up in Chapter 2, but we will explain this with some larger numbers. The compensation method is similar to that of addition, but works a bit differently.
    🔗

    Counting Down.

    If we are thinking of a problem like \(65 - 23\text{,}\) you can use counting down as starting at 65 and counting down 23. However, it’s easier to count first by 2 tens, then by 3 ones. The number line below shows this:
    🔗
    🔗

    Counting Up.

    Similar to counting down, if we have a problem like \(65-23\text{,}\) we start at 23 and count up to 65. However, first count up by tens to 63, then up 2 to 65. Visually, we can see this with:
    🔗
    and this shows that the result (difference) is the total number of hops or 42.
    🔗
    🔗

    Compensation.

    Similar to that of compensation with addition, we can simplify calculations involving subtraction. Consider the following:
    \begin{equation*} \begin{aligned} 34 - 18 \amp = 34 - 18 + (2-2) \qquad \text{using the additive identity property} \\ \amp = (34+2)-18-2 \qquad \text{using the any-order property} \\ \amp = 36 - 20 = 16 \end{aligned} \end{equation*}
    🔗
    Note: since one can add any number, typically it’s best to add or subtract a number to make the subtrahend a multiple of 10 (or as we will see later a multiple of 100). Note that if we subtract 4 from each like:
    \begin{equation*} \stackrel{-4}{34} - \stackrel{-4}{18} = 30 -14 = 16 \end{equation*}
    🔗
    is correct, however the calculation \(36-20\) is easier to do than \(30-14\text{.}\) Why?
    🔗
    🔗

    Compatible Numbers.

    Similar to that of compatible numbers for addition, compatible numbers for subtraction are those that are easier to do or result in “nice” numbers, like those with multiples of 10 or 100. The following are compatibles \(93-23\text{,}\) \(67-17\text{,}\) \(120-30\text{,}\) \(138-18\text{.}\) This allows us to do some operations like \(97 + 28 -17 - 8\text{.}\) If we work this from left to right:
    \begin{equation*} \begin{aligned} 97 + 28 -17 - 8 \amp = 125 - 17-8 \amp\amp\text{Add the first two numbers} \\ \amp = 108 - 8 \amp\amp\text{now subtract $125-17$}\\ \amp = 100 \end{aligned} \end{equation*}
    🔗
    and you should notice that the last operation was easy to do, but the first was not. Instead we can rearrange things as:
    \begin{equation*} \begin{aligned} 97 + 28 -17 - 8 \amp = (97-17)+(28-8) \amp\amp\text{rearrange for compatible numbers} \\ \amp = 80 +20 \\ \amp = 100 \end{aligned} \end{equation*}
    🔗
    and all of these operations are relatively easy to do.
    🔗
    🔗

    Evaluate the following subtraction problems using compensation:
    1. \(\displaystyle 54 - 37\)
      🔗
      🔗

      🔗
      🔗

      \begin{equation*} \stackrel{+7}{92} - \stackrel{+7}{43} = 99 - 50 = 49 \end{equation*}
      with the same result and this doesn’t require an unbundling.
      🔗
      🔗
    🔗
    🔗

    Subsection 4.1.3 Thinking Strategies for Multiplication

    Recall that there are three properties of multiplication that we saw in Section 2.4 as well as the distributive property. If \(a,b\) and \(c\) are whole numbers then
    🔗
    Multiplicative Identity
    🔗
    \begin{equation} 1 \times a = a\tag{4.1.4} \end{equation}
    🔗
    Multiplicative Commutative
    🔗
    \begin{equation} a \times b = b \times a\tag{4.1.5} \end{equation}
    🔗
    Multiplicative Associative
    🔗
    \begin{equation} (a \times b) \times c = a \times (b \times c)\tag{4.1.6} \end{equation}
    🔗
    Distributive Property
    🔗
    \begin{equation} (a+b) \times c = a \times c + b \times c\tag{4.1.7} \end{equation}
    🔗
    🔗
    There are 3 standard stages for teaching mathematics which we will cover. Before this, a student should be proficient at:
    • counting to 100,
      🔗
      🔗
    • addition doubles from \(1+1\) to \(10 + 10\text{,}\)
      🔗
      🔗
    • skip counting by 2, 3, 5 and 10.
      🔗
      🔗
    🔗

    Compatible Numbers and Any-Order Multiplication.

    Similar to that of addition, we can use any-order multiplication to do operations. Consider \(3 \times 5 \times 7 \times 4\text{.}\) Although we can go left to right in multiplication, it is simpler if we collect by compatible numbers. In this case, note that \(5 \times 4=20\text{,}\) which is an easy number to multiply.
    \begin{equation*} \begin{aligned} 3 \times 5 \times 7 \times 4 \amp = (4 \times 5) \times (3 \times 7) \amp\amp\text{Use any-order property} \\ \amp = 20 \times 21 = 420 \amp\amp\text{think of doubling 21 then multiply by 10} \ \end{aligned} \end{equation*}
    🔗
    🔗

    Compensation with Multiplication.

    Compensation is a good thinking strategy for pairs of numbers that can be done easier in a little different form. For example, if have \(36 \times 15\text{,}\) we can write \(36 = 18 \times 2\) and then use the associative property.
    \begin{equation*} 24 \times 15 = 12 \times 2 \times 15 = 12 \times 30 = 360 \end{equation*}
    🔗
    The following show a few other examples:
    🔗

      🔗

    1. \begin{equation*} 50 \times 14 = 50 \times 2 \times 7 = 100 \times 7 = 700 \end{equation*}

    Multiplying by 4,5,8,9,10,25,100.

    The numbers 4,5,8,9,10,25,100 are easier to multiply than other numbers. When you see these, take advantage of the following strategies.
    🔗
    🔗

    Multiply by 4.

    Just double the number twice. For example,
    \begin{equation*} \begin{aligned} 4 \times 14 \amp= 2 \times 28 = 56 \\ 4 \times 130 \amp = 2 \times 260 = 520 \end{aligned} \end{equation*}
    🔗
    🔗

    Multiply by 5.

    Take the number and halve then multiply by 10 (or flip the order of this). For example,
    \begin{equation*} \begin{aligned} 18 \times 5 \amp = 9 \times 10 = 90 \\ 540 \times 5 \amp = 270 \times 10 = 2700 \end{aligned} \end{equation*}
    🔗
    🔗

    Multiply by 9.

    Use the rule \(9x=10x-x\text{.}\) That is multiply by 10 then subtract the number. For example,
    \begin{equation*} \begin{aligned} 35 \times 9 \amp = 350 - 35 = 315 \\ 87 \times 9 \amp = \stackrel{+13}{870} - \stackrel{13}{87}\amp\amp\text{Use compensation} \\ \amp = 883-100 = 783 \end{aligned} \end{equation*}
    🔗
    🔗

    Multiply by 10.

    Append a 0 to the end of the number. For example,
    \begin{equation*} \begin{aligned} 91 \times 10 \amp = 910 \\ 87392 \times 10 \amp = 873920 \end{aligned} \end{equation*}
    🔗
    🔗

    Multiply by 25.

    Multiply the number by 100 and divide by 4 (or flip the order). Note: we will see division by 4 below, but you can divide by 2 twice. For example,
    \begin{equation*} \begin{aligned} 44 \times 25 \amp = 11 \times 100 = 1100\amp\amp\text{Recall $44\div 4 = 22 \div 2 = 11$}\\ 164 \times 25 \amp = 41 \times 100 = 4100\amp\amp\text{Note that $164\div 4 = 82 \div 2 = 41$} \end{aligned} \end{equation*}
    🔗
    🔗

    Multiply by 100.

    Append two zeros to the end of the number. For example,
    \begin{equation*} \begin{aligned} 25 \times 100 \amp = 2500 \\ 5836 \times 100 \amp = 583600 \end{aligned} \end{equation*}

    🔗

    Subsection 4.1.4 Thinking Strategies for Division

    Compensation.

    Compensation for division uses properties of division and we’ll assume that the result of the division has no remainder. Let \(n = k \cdot a\text{,}\) that is that \(n\) is a multiple of \(a\text{,}\) the divisor. Also, assume that \(n\) and \(a\) have a common factor, \(m\text{,}\) that is \(n=i \cdot m\) and \(a = j \cdot m\text{,}\) therefore we can write:
    \begin{equation*} n \div a = (i \cdot m) \div (j \cdot m) = i \div j \end{equation*}
    🔗
    There are a number of common places where compensation is nice to do with division as the following examples show.
    🔗
    🔗

    Divide by 4.

    Halve twice. For example,
    \begin{equation*} 48 \div 4 = 24 \div 2 = 12 \end{equation*}
    🔗
    🔗

    Divide by 5.

    Double then divide by 10. For example,
    \begin{equation*} \begin{aligned} 270 \div 5 = 540 \div 10 = 54 \\ 405 \div 5 = 810 \div 10 = 81 \end{aligned} \end{equation*}
    🔗
    🔗

    Divide by 10.

    Remove a zero from the end of the number. For example,
    \begin{equation*} \begin{aligned} 1850 \div 10 = 185 \\ 2840 \div 10 = 284 \end{aligned} \end{equation*}
    🔗
    🔗

    Divide by 25.

    Multiply by 4 then divide by 100. This is generally easiest to think of doubling twice. The following examples show an good way to think about this.
    \begin{equation*} 175 \div 25 = 350 \div 50 = 700 \div 100 = 7 \end{equation*}
    or
    \begin{equation*} 2050 \div 25 = 4100 \div 50 = 8200 \div 100 = 82 \end{equation*}
    🔗
    🔗
    🔗

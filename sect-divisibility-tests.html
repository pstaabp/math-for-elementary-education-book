    Section 6.2 Divisibility Tests

    There are a number of cases when it is advantageous to know if numbers divide other numbers evenly.
    🔗
    • You would wonder if there were 23 gloves in a box near a classroom. Which glove is missing its pair?
      🔗
      🔗
    • Why isn’t 568 a reasonable answer if a student multiplied another number by 3?
      🔗
      🔗
    🔗
    For the first, example, you know that 2 does not divide 23 evenly because of the divisibility test that an even number ends in 0,2,4,6 or 8. (We will prove this soon). For the second example, we use use a divisibility by 3 test to show that a number is only divisible by 3 if the sum of its digits is also divisible by 3. (What is the sum of the digits in 568?)
    🔗
    We will also develop divisibility tests for 4,5,8,9,10 and 11.
    🔗

    Definition 6.2.1.

    We say “\(A\) is divisible by \(k\)” whenever \(A\) is a multiple of \(k\text{,}\) that if \(A=k \cdot a\) for some whole number \(a\text{.}\) In addition, the following phrases have the same meaning:
    🔗
    • \(A\) is divisible by \(k\)
      🔗
      🔗
    • \(k\) divides \(A\)
      🔗
      🔗
    • \(A\) is a multiple of \(k\)
      🔗
      🔗
    • \(k\) is a factor of \(A\text{.}\)
      🔗
      🔗
    🔗
    🔗
    Recall that the Quotient-Remainder theorem states that for any pair of whole numbers \(A\) and \(k\) that there exist unique numbers \(a\) and \(r\) such that \(A=a\cdot k+r\text{,}\) which we often think of as \(A \div k= a\;R\;r\text{.}\)
    🔗
    Divisibility, in short, means that \(r=0\text{,}\) that there is no remainder.
    🔗

    Subsection 6.2.2 Long Division and Divisibility

    Recall as discussed above, a number \(A\) is divisible by \(k\text{,}\) if under division, there is no remainder. For larger numbers, we can use long division to do this and check the remainder. The following example shows this.
    🔗

    Example 6.2.2.

    Does 9 divide 4725?
    🔗
    Solution.
    We can use long division to determine this.
    🔗
    47259 And since the remainder is 0, this means that yes, 9 divides 4725.
    🔗
    🔗
    🔗
    The next two examples shows that we can use our mental math skills to check divisibility in some cases relatively easily.
    🔗

    Example 6.2.3.

    Use mental math to determine if 3 divides 912.
    🔗
    Solution.
    We can do this first recognizing that \(912=900+12\) so
    \begin{equation*} 912 \div 3 = (900 + 12) \div 3 = 900 \div 3 + 12 \div 3 = 300 + 4 = 304. \end{equation*}
    🔗
    🔗
    🔗

    Example 6.2.4.

    Use mental math to determine if 6 divides 1240.
    🔗
    Solution.
    Similar to the example above, recognize that \(1240 = 1200 + 40\) so
    \begin{equation*} 1240 \div = (1200+40) \div 6 = 1200 \div 6 + 40 \div 6 = 200 + (6 \; R \; 6) \end{equation*}
    🔗
    So 6 does not divide 1240.
    🔗
    🔗
    🔗
    🔗

    Subsection 6.2.3 Divisibility Lemma

    In each of the two examples above, notice that we have taken a relatively large number and written it as the sum of two number, the first of which is divisible. The following lemma generalizes this idea:
    🔗

    Lemma 6.2.5. Divisibility Lemma.

    Suppose \(A\) is a number divisible by \(k\text{.}\) Then
    • If \(B\) is divisible by \(k\text{,}\) then \(A+B\) is divisible by \(k\text{.}\)
      🔗
      🔗
    • If \(B\) is not divisible by \(k\text{,}\) then \(A+B\) is not divisible by \(k\text{.}\)
      🔗
      🔗
    🔗
    🔗
    Above we showed that \(1240\) is not divisible by \(6\text{.}\) The following example uses the divisibility lemma to do this.
    🔗

    Example 6.2.6.

    Use the divisibility lemma to show that \(1240\) is not divisible by \(6\text{.}\)
    🔗
    🔗
    First, notice that we can write \(1240=1200+40\text{,}\) so this will be \(A=1200\) and \(B=40\text{.}\) It is important that the first number is divisible by \(k\text{,}\) in this case \(6\text{.}\) Because \(B=40\) is not divisible by 6, the divisibility lemmas shows that \(1240\) is not divisible by 6.
    🔗
    🔗

    Example 6.2.7.

    Is \(4235\) divisible by 7?
    🔗
    Solution.
    We will use the divisibility lemma to show this and write \(4235=4200+35\text{,}\) noting that the first number, \(A=4200\) is divisible by 7 because \(A=7\cdot 600\) and \(B=35\) is also divisible by 7, so \(4235\) is divisible by 7.
    🔗
    🔗
    🔗
    Now, we tackle the proof of the divisibility lemma.
    🔗

    Picture Proof of the Divisibility Lemma.
    Recall that the theorem assumption is that \(A\) is divisible by \(k\text{.}\)
    🔗
    First, we will show that if \(B\) is divisible by \(k\) then \((A+B)\) is divisible by \(k\text{.}\)
    🔗
    The picture shows that \(A\) is evenly \(k\) rows of some number as well as \(B\) is evenly \(k\) rows of some (maybe different) number. The result shows that \(A+B\) (the total of \(A\) and \(B\)) is divisible by \(k\text{.}\)
    🔗
    The same picture shows the result that if \(A+B\) is divisible by \(k\) (indicated by \(A+B\) is \(k\) rows of some number). Then \(B\) is divisible by \(k\text{.}\) (indicated that \(B\) is \(k\) rows of some number).
    🔗
    🔗
    Note: many of the lemmas and divisibility theorems in this chapter are proven in Section 6.5 later in this chapter and the algebraic proof of the Divisibility Lemma is one of these.
    🔗

    Theorem 6.2.8.

    Divisibility Test for 2,4,5,8,10 A number is divisible
    • by 10 if and only if its last digit is 0,
      🔗
      🔗
    • by 5 if and only if its last digit is 0 or 5,
      🔗
      🔗
    • by 2 if and only if its last digits is 0,2,4,6 or 8,
      🔗
      🔗
    • by 4 if and only if its last two digits are a number divisible by 4,
      🔗
      🔗
    • by 8 if and only if its last three digits are a number divisible by 8.
      🔗
      🔗
    🔗
    🔗

    Example 6.2.9.

    • 5,280 is divisible by 10 because its last digit is 0.
      🔗
      🔗
    • 5,280 is divisible by 5 because its last digit is 0.
      🔗
      🔗
    • 5,280 is divisible by 2 because its last digit is 0.
      🔗
      🔗
    • 5,280 is divisible by 4 because its last two digits (80) are divisible by 4.
      🔗
      🔗
    • 5,280 is divisible by 8 because its last three digits are divisible by 8.
      🔗
      🔗
    🔗
    🔗

    Of the Divisible by 2.
    Let a whole number \(N\) be written as
    \begin{equation*} N = 10 a + b \end{equation*}
    🔗
    (why can it be written this way?) Since \(10a\) can be written as \(2 \cdot (5a)\text{,}\) it is divisible by 2. In addition, \(b\) is divisible by 2 if and only if \(b\) is 0, 2, 4, 6, or 8. By the divisibility theorem, \(N\) is divisible by 2 if and only if \(10a\) and \(b\) are divisible by 2.
    🔗
    🔗

    Theorem 6.2.10.

    Divisibility Test for 3 and 9 A number is divisible
    • by 3 if and only if the sum of the digits is divisible by 3,
      🔗
      🔗
    • by 9 if and only if the sum of the digits is divisible by 9,
      🔗
      🔗
    🔗
    🔗

    Example 6.2.11.

    Using the Divisibility Test for 3 Determine if the following are divisible by 3:
    1. 18,390
      🔗
      🔗
    2. 293,456
      🔗
      🔗
    🔗
    🔗
    1. Since \(1+8+3+9+0 = 21\text{,}\) since 21 is divisible by 3, then 18,390 is divisible by 3.
      🔗
      🔗
    2. Since \(2+9+3+4+5+6 = 29\text{,}\) since 29 is not divisible by 3, then 293,456 is not divisible by 3.
      🔗
      🔗
    🔗
    🔗

    Example 6.2.12.

    Using the Divisibility Test for 9 Determine if the following are divisible by 9:
    1. 18,390
      🔗
      🔗
    2. 293,454
      🔗
      🔗
    🔗
    1. Since \(1+8+3+9+0 = 21\text{,}\) since 21 is not divisible by 9, then 18,390 is not divisible by 9.
      🔗
      🔗
    2. Since \(2+9+3+4+5+4 = 27\text{,}\) since 27 is divisible by 9, then 293,456 is divisible by 9.
      🔗
      🔗

    Subsection 6.2.4 Divisibility Test for 11

    Theorem 6.2.13.

    Divisibility Test for 11 A number is divisible by 11 if and only if the number formed by
    \begin{equation*} \text{(sum of odd-position digits)}-\text{(sum of even-position digits)} \end{equation*}
    🔗
    is a multiple (whether positive, negative or 0) of 11.
    🔗
    🔗

    Remark 6.2.14.

    Make sure that you carefully read the test for 11. Note that the sum is the odd-positioned digits, like the first, third, fifth, etc. and the even-positioned digits, like the 2nd, 4th, etc.It is common to mix this up with adding even and odd digits, but this is not what the test says.
    🔗
    🔗

    Example 6.2.15.

    Divisibility Test for 11 Determine if the following are divisible by 11:
    🔗
    1. 93,412
      🔗
      🔗
    2. 208,273
      🔗
      🔗
    🔗
    Solution.
    1. \begin{equation*} (9+4+2) - (3+1) = 15-4=11 \end{equation*}
      so 93,412 is divisible by 11.
      🔗
      🔗
    2. \begin{equation*} (2+8+7) - (0+2+3) = 17-5 = 12 \end{equation*}
      which is not divisible by 11, so 208,273 is not divisible by 11.
      🔗
      🔗

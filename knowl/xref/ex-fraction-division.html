Example 7.4.10.

Find \(\frac{10}{3}\div \frac{2}{3}\text{.}\)
🔗
Solution.
Let’s first assume that this a measurement interpretation. The we can create a diagram that shows the total length (10/3 or the dividend) and the length of the part (2/3 or the divisor)
🔗
From this diagram, it would take 5 units to make the length of \(10/3\text{,}\) so the answer is 5.
🔗
If instead, we do partitive division, then this can be interpreted as “\(10/3\) is \(2/3\) of what size?”
🔗
From this diagram, 2 units have length \(10/3\) so 1 unit is \(5/3\text{.}\) To get one full length is 3 units or \(15/3=5\text{,}\) the same answer as above.

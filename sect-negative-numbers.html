    Section 9.1 Negative Numbers

    Objectives

    • Understanding models for integers.
      🔗
      🔗
    • Understanding negative numbers and some rules associated with negative numbers.
      🔗
      🔗
    🔗
    Negative numbers are most easily introduced with the number line
    🔗
    which extends the number line backwards (to the left)
    🔗

    Definition 9.1.1.

    The integers are the numbers
    \begin{equation*} \{ \ldots, -3,-2,-1,0,1,2,3,\ldots \} \end{equation*}
    and the number greater than zero are called positive numbers and those less than 0 are called negative.
    🔗
    The numbers \(0,1,2,\ldots\) (zero and the positive numbers) are called nonnegative integers. The numbers \(\ldots, -3,-2,-1,0\) (the negative numbers and zero) called the nonpositive numbers.
    🔗
    🔗

    Subsection 9.1.1 Models for the integers

    Temperature
    🔗
    In the two standard ways of measuring temperature (Fahrenheit and Celsius), there are both negative and positive temperature and using a scale like a thermometer shows the relationship.
    🔗
    One should note though that temperature (like any measurement) does not have to just be an integer and any real number is possible.
    🔗
    Elevation
    🔗
    We typically take the elevation of a point on land (measured in either feet or meters) as positive for those points above sea level and depths in the ocean as negative number.
    🔗
    🔗
    These model will be developed below with details.
    🔗
    🔗

    Subsection 9.1.2 Basics of Integers

    Understanding the number line is key to understanding integers.
    🔗
    First, the numbers to the left of 0 are the negative numbers and the more to the left, the more negative a number is and the bigger the number without the negative sign is.
    🔗
    Also, the negative symbol like \(-3\) is the same number for subtraction and may be difficult for students new to them to understand what this means.
    🔗

    Distance.

    The notion of how far a number is from zero is quite important. We call this the distance from 0. The numbers \(3\) and \(-3\) are both 3 from 0. Looking at the number line above, \(3\) is three steps to the right of 0 and \(-3\) is three steps to the left.
    🔗
    The idea of absolute value is the distance from zero and is introduced about the same time as negative numbers. Using the example above, \(|3|=3\) and \(|-3|=3\text{.}\)
    🔗
    🔗

    Opposite Numbers.

    Every integer \(a\) has an opposite, which we denote \(-a\text{.}\) The number \(-a\) is the same distance from 0 as \(a\) but is located in the opposite direction, \(a\text{.}\) The number line can help with this:
    🔗
    The number \(-5\) is opposite of \(5\) and the number \(5\) is opposite \(-5\text{.}\)
    🔗
    We can generalize opposite numbers in the following property of integers.
    🔗
    Property 9.1.2. Additive Inverse Property.
    For each integer \(a\text{,}\) there exists a unique integer called the opposite of \(a\) denoted by \(-a\) which satisfies
    \begin{equation*} a+(-a) = 0 \end{equation*}
    🔗
    🔗
    The diagram above shows the following property of integers:
    🔗
    Property 9.1.3. Opposite Integers.
    \(-(-a) =a \) for any integer \(a\)
    🔗
    🔗
    From the diagram above, starting at \(-a\text{,}\) this says that the opposite of this (which is \(-(-a)\) ) is just \(a\text{.}\) Another way to look at this if we start at \(a\text{,}\) the number on the right, then find the opposite to get to \(-a\text{,}\) then take the opposite again, we return to \(a\text{.}\)
    🔗
    A few other things to note about this:
    🔗
    • Don’t forget that this also applies to negative numbers. that is if \(a=-7\text{,}\) then \(-(-(-7))=-7\text{.}\)
      🔗
      🔗
    • Don’t read this rule as saying \((-1)\cdot(-1)=1\text{.}\) This isn’t talking about multiplication.
      🔗
      🔗
    🔗
    🔗

    Ordering Integers.

    We order all integers in the same way that we order all whole numbers. If \(a\) is to the right of \(b\) on the number line, then we say \(a \lt b\text{.}\) If \(a\) is to the left of \(b\text{,}\) then we say \(a \gt b\text{.}\)
    🔗
    🔗
    🔗

    Subsection 9.1.3 Integer Addition

    How do we do addition with integers (positive and negatives). There are four cases and we go through each in detail:
    🔗

    Positive \(+\) Positive:.

    We’ve done this already. Typically, recall that we can think of this as “counting on” and the number line. Find \(5+3\)
    🔗
    🔗

    Negative \(+\) Positive.

    This works the same way because the second number is positive. We start at the first number and again ``count on’’. The figure below shows \(-4+3=-1\)
    🔗
    🔗

    Positive \(+\) Negative.

    If we think of the ``count on’’ again with this, let’s see what happens. Try \(5+(-3)\) so we start at 5 and count up \(-3\) and to determine this, we use the notion that \(-3\) is the opposite of \(3\text{,}\) so we interpret \(5+(-3)\) as start at 5 and count down 3.
    🔗
    We will use this model to also explain that \(5+(-3)=5-3\text{.}\)
    🔗
    🔗

    Negative \(+\) Negative:.

    Once we understand the previous case, this is interpreted the same way. Consider \(-3+(-2)\text{.}\) This means start at \(-3\) and count down \(2\text{.}\)
    🔗
    🔗
    The last two examples of adding a negative integer results in the following property
    🔗

    Property 9.1.4. Addition of a negative integer.

    \(a+(-b) = a-b\) for any two integers \(a,b\text{.}\)
    🔗
    🔗
    The idea behind this is that the term \(-b\) is interpreted as the opposite of \(b\text{.}\) If \(b \gt 0\text{,}\) then \(a+(-b)\) starts at \(a\) on the number line and hops left \(b\) units. This is the same as subtraction.
    🔗
    🔗

    Subsection 9.1.4 Other models for Integers

    Above, we had the models of temperature and elevation as ways to understand negative numbers. We end this section we three additional models.
    🔗

    Vector Model.

    Each number is represented as a vector (arrow) along the number line. The following shows \(5+(-3)\text{.}\)
    🔗
    🔗

    Chip Model.

    In this case chips can be used (one color for positive numbers and another for negative numbers) and combine the opposite colors and remove.
    🔗
    The following can be used to show \(5 + (-3)\text{.}\)
    🔗
    The line through the two colors cancel each other out. The result is the two blue (represent \(+2\) ).
    🔗
    This can be a problem if you can’t remember which color represents positive/negative.
    🔗
    🔗

    Money Model.

    Money can be used to investigate negative numbers. Money that you have (assets) are generally thought of as positive numbers. Debits (or money that you owe) can be thought of a negative numbers.
    🔗
    This can be shown abstractly with the chip model above, or can be used with manipulative that look like money. In that case, it needs to be clear that the money that a student has in the positive numbers and there is something representing costs like a purchased object.
    🔗
    🔗

    Patterns in Addition.

    Our last model is to generate patterns in addition. We will add a number of integers to 4.
    \begin{align*} 4 + 3 \amp = 7 \\ 4 + 2 \amp = 6 \\ 4 + 1 \amp = 5 \\ 4 + 0 \amp = 4 \\ 4 + (-1) = \amp ? \end{align*}
    and looking at the pattern, it appears the last one will be 3. We can continue this a bit further:
    \begin{align*} 4 + (-1) \amp = 3\\ 4 + (-2) \amp = 2\\ 4 + (-3) \amp = 1 \end{align*}
    🔗
    🔗
    🔗

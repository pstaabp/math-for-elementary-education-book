    Subsection 2.2.1 Properties of Addition

    There are three properties of addition that you probably know just by understanding addition.
    🔗

    Property 2.2.3.

    For any whole numbers, \(a, b, c\text{,}\) each of the following hold:
    🔗
    Additive Identity
    🔗
    \begin{equation*} a+0=a \end{equation*}
    🔗
    Commutative Property
    🔗
    \begin{equation*} a+b = b+a \end{equation*}
    🔗
    Associative Property
    🔗
    \begin{equation*} (a+b) + c = a + (b+c) \end{equation*}
    🔗
    🔗
    🔗
    The additive identity property shows that adding 0 to any number doesn’t change the number. This make a lot of sense after understanding the concept of 0. The commutative property shows that the sum of two numbers is independent of the order of the two numbers. The associative property relies on recalling that when parentheses are present, that one must do the operation inside the parentheses first. This shows if you add the first two then add the result to the 3, the sum is the same as adding the last two, then adding to the first.
    🔗

    Example 2.2.4.

    What property is being used in each of the following?
    🔗
    1. \(\displaystyle (6+2)+4 = (2+6) + 4\)
      🔗
      🔗
    2. \(\displaystyle (2+6)+4 = 2+(6+4)\)
      🔗
      🔗
    3. \(7+0=7\text{.}\)
      🔗
      🔗
    🔗
    🔗
    1. This is the commutative property. Notice that there are three numbers, but the first two swap places.
      🔗
      🔗
    2. This is the associative property. Notice that we have changed the order of operations.
      🔗
      🔗
    3. This is the additive identity.
      🔗
      🔗
    🔗
    🔗

    Lemma 2.2.5. Any-Order Property of Addition.

    The sum \(a+b+c\) can be done in any order.
    🔗
    🔗
    We won’t present a formal proof here, but this is a consequence of the the commutative and associative properties.
    🔗

    Corollary 2.2.6. Extended Any-Order Property.

    The sum of any number of addends can be done in any order.
    🔗
    🔗
    Again, no formal proof will be done here but this is a consequence of a number of applications of the commutative and associative properties. The following show an example.
    🔗

    Example 2.2.7.

    The numbers: \(3+2+4+7\) can be added in any order. For example:
    \begin{equation*} \begin{aligned} (3+2)+(4+7) \amp = 5 + 11 = 16\\ (7+3) + (2+4) \amp = 10 + 6 = 16\\ (3+4) + (2+7) \amp = 7 + 9 = 16 \end{aligned} \end{equation*}
    are all valid ways to add the 4 numbers.
    🔗
    🔗
    In Chapter 4, we will use this property to our advantage to rearrange the sum of numbers to pair up number that we call compatible in which the result is easier to compute.
    🔗
    🔗

    Subsection 2.2.3 Addition and Place Value

    There are multiple approaches to understanding addition and place value. First, using the expanded form of a number, then a chip model and finally the DLB model.
    🔗

    Expanded Form:.

    As seen above, an addition like \(13+24\) is relatively straightforward once a student understands place value. If we used expanded form on these:
    🔗
    \begin{equation*} \begin{aligned} 13+24\amp= (10+3)+(20+4) \qquad\text{use any-order property}\\ \amp= (10+20) + (3+4) \\ \amp= 30 + 7 = 37\end{aligned} \end{equation*}
    🔗
    This gets a bit more more complicated when the total number of ones (pennies) exceeds 9. For example, \(25 + 37\) can be written as
    \begin{equation*} \begin{aligned} 25 + 37\amp= (20 + 5) + (30 + 7) \qquad \text{ Use the any-order property,}\\ \amp= (20 + 30) + (5+7) \\ \amp= 50 + 12 \\ \amp= 50 + 10 + 2 \\ \amp= 60 + 2 = 62 \end{aligned} \end{equation*}
    🔗
    The writing of \(5+7=12=10+2\) is called composing a ten or bundling as we will see with models below.
     1 
    Notice the way that we write these operations. We start with the original problem, and link each step with an equals sign. This is an important skill to develop and we will work on this in Chapter 4. Until we get there, pay attention to the steps and how they are written.
    🔗
    🔗

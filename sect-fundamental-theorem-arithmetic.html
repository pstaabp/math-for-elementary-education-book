    Section 6.3 Primes and the Fundamental Theorem of Arithmetic

    We can write often whole numbers as products of other whole numbers. For example
    \begin{equation*} 30 = 6 \cdot 5 \end{equation*}
    and we can further write \(6=2 \cdot 3\text{,}\) therefore
    \begin{equation*} 30 = 2 \cdot 3 \cdot 5 \end{equation*}
    🔗
    The number 2, 3 and 5 can no longer be written as multiples of other numbers and thus called prime numbers.
    🔗

    Definition 6.3.1.

    A prime number is a whole number \(P \gt 1\) whose only factors are 1 and \(P\text{.}\) Whole numbers \(N\geq 2\) that are not prime are called composite.
    🔗
    🔗

    Remark 6.3.2. Sieve of Eratosthenes.

    To find a list of prime below a number, \(N\) using the sieve of Eratosthenes,
    1. Write a grid of numbers starting at 2 and up to \(N\text{.}\) It is nice to use rows of 12 as shown above, and rows of 15 or 18 are nice too, but neither is a requirement.
      🔗
      🔗
    2. Circle the lowest uncrossed out number.
      🔗
      🔗
    3. Cross out all multiples of that number.
      🔗
      🔗
    4. Repeat steps 2 and 3 until all numbers are circled or cross out
      🔗
      🔗
    The circled numbers are prime.
    🔗
    🔗

    Theorem 6.3.3. Fundamental Theorem of Arithmetic.

    Every whole number \(N \gt 1\text{,}\) can be written as a product of primes and this can only be done one way (except for reordering).
    🔗
    🔗
    Knowing how to write whole numbers in term of its prime factors is an important step in understanding the structure of whole numbers and operations on them. We show an efficient way to do this in the next section.
    🔗
    🔗

    Subsection 6.3.3 Primality Test

    From the last section, we saw using the Sieve of Eratosthenes that we can find the first handful of prime numbers. This is great for finding the first few primes, but what if we want to determine if 1151 is prime? We still need to determine if the only factors are 1 and itself, but we can use the following theorem:
    🔗

    Theorem 6.3.6. Primality Test.

    A whole number \(N \gt 1\) is prime unless it has a prime factor \(p \leq \sqrt{N}\text{.}\) Thus to test whether \(N\) is prime one need only check divisibility by the primes \(p=2,3,5,\ldots\) that satisfy \(p^{2}\leq N\text{.}\)
    🔗
    🔗
    This theorem can be turned into an algorithm to determine if a number is prime.
    🔗

    Note 6.3.7. Algorithm to Test a Number for Primality.

    This basically gives use a recipe (called an algorithm) for determining if a number \(N\) is prime:
    🔗
    1. Check if 2 is a factor (use the divisibility test).
      🔗
      🔗
    2. Check if 3 is a factor (use the divisibility test).
      🔗
      🔗
    3. Check if 5 is a factor (use the divisibility test).
      🔗
      🔗
    4. Check if 7 is a factor (there is no divisibility test, so use the divisibility lemma or long division).
      🔗
      🔗
    5. Check if 11 is a factor (use the divisibility test).
      🔗
      🔗
    6. Continue for \(p=13, 17, \ldots\)
      🔗
      🔗
    7. If any of the primes are a factor, stop, the number \(N\) is not prime.
      🔗
      🔗
    8. If you reach \(p^{2} \gt; N\text{,}\) then stop, the number is prime.
      🔗
      🔗
    🔗
    🔗
    Let’s see how this works with an example.
    🔗

    Example 6.3.8.

    Is 203 prime?
    🔗
    Solution.
    First of all the square root of 203 is between 13 and 15 (since \(13^{2}=169\) and \(15^{2}=225\)), so we need to check if 203 is divisible by 2,3,5,7,11, and 13.
    🔗
    • 203 isn’t divisible by 2 (ends in a 3)
      🔗
      🔗
    • 203 is not divisible by 3 (sum of digits is 5)
      🔗
      🔗
    • 203 is not divisible by 5 (doesn’t end in 0 or 5)
      🔗
      🔗
    • 203 is divisible by 7. This can be checked with some mental math or long division. Using the Divisibility Lemma, \(203 = 210 - 7 = 7 \cdot (30 -1 ) = 7 \cdot 29\text{.}\) Using long division, \(203 \div 7 = 29 R0\)
      🔗
      🔗
    🔗
    At this point we stop because we found a pair of factors. This shows that \(203=7 \cdot 29\text{,}\) so this isn’t prime.
    🔗
    🔗
    🔗
    Here’s another example
    🔗

    Example 6.3.9.

    Is 293 prime?
    🔗
    Solution.
    🔗
    First, let’s determine which primes we need to check. Since \(17^{2}=289\) and \(23^{2}=529\text{,}\) we can check up through 17.
    🔗
    • 293 isn’t divisible by 2 (ends in a 3)
      🔗
      🔗
    • 293 is not divisible by 3 (sum of digits is 14, not a multiple of 3)
      🔗
      🔗
    • 293 is not divisible by 5 (doesn’t end in 0 or 5)
      🔗
      🔗
    • 293 is not divisible by 7: This can either be done with long division or using the Divisibility Lemma 6.2.5. \(293 = 280 + 13 = 7 \cdot 40 + 13 \) and since 13 is not divisible by 7, then 293 is not either. Using long division show: \(293 = 41 R 6\)
      🔗
      🔗
    • 293 is not divisible by 11. Use the divisibility test \(2+3-9 = 5-9=-4\text{,}\) which is not a multiple of 11.
      🔗
      🔗
    • Check if 293 is divisible by 13. Using long division, \(293 \div 13 = 22 R 7\) and since there is a nonzero remainder, it is not divisible by 13.
      🔗
      🔗
    • Check if 293 is divisible by 17. Using long division, \(293 \div 17 = 17 R 4\) and since there is a nonzero remainder, it is not divisible by 17.
      🔗
      🔗
    🔗
    Since no primes \(p\) than satisfy \(p^2 \lt N\text{,}\) then 293 is prime.
